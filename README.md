Um portfólio web moderno, altamente responsivo e otimizado, desenvolvido para apresentar projetos, habilidades técnicas, certificações e trajetórias profissionais na área de desenvolvimento de software e infraestrutura.

---

## ✨ Funcionalidades e Destaques

- **Design Dark Mode Moderno:** Interface com estética Glassmorphism e esquemas de cores confortáveis para leitura (*Indigo/Violet*).
- **Navegação Fluida:** Transições suaves entre seções e navegação intuitiva.
- **Destaques de Hard Skills:** Organização clara de competências em Front-end, Back-end, Redes e Cibersegurança.
- **Ações Rápidas:** Botões diretos para download do CV atualizado em PDF e contato rápido.
- **Totalmente Responsivo:** Adaptado para diferentes resoluções (Mobile, Tablet e Desktop).

---

## 🛠️ Tecnologias Utilizadas

- **Estruturação:** HTML5 Semântico
- **Estilização:** CSS3 Moderno (Flexbox, CSS Grid, Variáveis CSS, Glassmorphism)
- **Ícones:** [Boxicons](https://boxicons.com/)
