Portfólio web moderno, altamente responsivo e otimizado, desenvolvido para apresentar meus projetos, competências técnicas, certificações e trajetória profissional na área de desenvolvimento de software, infraestrutura e segurança.

---

## ✨ Funcionalidades e Destaques

- **Design Dark Mode Moderno:** Interface com estética *Glassmorphism* e paleta de cores sóbria em tom *Indigo/Violet* para conforto visual.
- **Seção Sobre Mim Completa:** Apresentação detalhada da minha formação multiárea, certificações e experiências de impacto social.
- **Cards de Competências & Destaques:** Organização clara de habilidades em Front-end, Back-end, Redes e Cibersegurança.
- **Ações Rápidas:** Botões para download direto do currículo em PDF e redirecionamento para contato.
- **Layout Responsivo:** Adaptado para navegação fluida em dispositivos móveis, tablets e desktops.

---

## 🛠️ Tecnologias Utilizadas

- **Estruturação:** HTML5 Semântico
- **Estilização:** CSS3 Moderno (Flexbox, CSS Grid, Variáveis CSS, Glassmorphism)
- **Ícones:** [Boxicons](https://boxicons.com/)
